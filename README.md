# I2C-sensors-OLED-Displays
In this lab, I learned how to build an environmental monitoring system with an Arduino Uno. I used I2C to read temperature, humidity, and pressure from a BMP280 sensor, and SPI to show the results in real time on an OLED display.
# Required Equipment
- Arduino Uno
- BMP280 Sensor Module
- Waveshare OLED Display
- Breadboard
- Jumper Wires
- USB Cable
- ESP32 Kit
# Software
- Visual Studio Code
- PlatformIO
- Serial Monitor
